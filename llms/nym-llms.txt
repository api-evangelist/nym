# Nym

> Nym is a healthcare technology company providing autonomous medical coding for health systems, hospitals, and physician groups. Its proprietary Clinical Language Understanding (CLU) engine reads clinical documentation and assigns accurate medical codes (ICD-10, CPT, E/M) using transparent, rules-based coding logic rather than generic NLP. Nym is not currently a public API provider — it exposes no developer API, SDK, or developer portal — so this profile is a company/network entry, not an API catalog.
